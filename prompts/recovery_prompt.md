# 仓库恢复提示

请在仓库根目录工作，并按以下顺序恢复上下文：

1. 阅读 `AGENTS.md`。
2. 阅读 `docs/architecture/overview.md`。
3. 阅读 `docs/handover/current_status.md`、`next_steps.md` 和 `known_issues.md`。
4. 仅打开与当前任务直接相关的 `docs/sessions/` 文件。
5. 检查 Git 状态，保护用户已有修改。
6. 用代码、测试和 Git 历史区分已确认、推断与未知。

输出当前目标、相关模块、验证命令、风险和前三个可执行步骤。不得补造缺失历史，不得输出秘密或本机绝对路径。
