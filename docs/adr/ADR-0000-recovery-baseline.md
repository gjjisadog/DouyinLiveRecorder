# ADR-0000：仓库恢复与交接基线

- 状态：Accepted
- 日期：2026-04-01

## 背景

仓库同时包含旧多平台 CLI、Windows 客户端和 Docker/NAS 运行方式，需要用可验证文档保持边界清晰。

## 决策

1. `AGENTS.md` 记录仓库级约束和验证命令。
2. `docs/architecture/overview.md` 记录稳定入口与模块边界。
3. `docs/handover/` 仅记录当前状态、下一步和已知问题。
4. `docs/sessions/` 保存每次阶段工作的范围和证据。
5. 未知事实明确标记为待验证，不从缺失历史推断结论。
6. 文本统一使用 UTF-8 和仓库相对路径。

## 影响

- 新任务可从少量稳定文件恢复上下文。
- GUI、Docker、NAS 和旧 CLI 的验证证据保持分离。
- 历史记录不得包含秘密或开发者本机绝对路径。
